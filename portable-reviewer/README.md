# 随身复习器 v0.1 · UI v2

这是 Study Protocol 的独立参考客户端，只做闪卡/挖空的短提取。协议仍为 `study-pack/0.1` + `study-events/0.1`，本轮 UI v2 只升级移动端视觉、信息层级、触控与交互反馈。

## 视觉与交互

- 与桌面工作台统一为“金石理性 × 纸本编辑部”的视觉语言。
- 深色外壳承担环境与导航，暖纸题页承担阅读与主动提取。
- 来源采用边注语义，答案采用揭页语义，四档自评采用低干扰状态按键。
- 支持系统浅色/深色、320/390/430px 窄屏、`prefers-reduced-motion`。
- 文件导入入口支持键盘焦点与 Enter/Space 触发。
- 记录中的事件数量会持续显示为“待同步”，可选设备震动仅作为辅助触感，不承担信息。

## 典型路径

1. 桌面工作台 -> 设置与数据 -> 导出今日 StudyPack。
2. 将 JSON 文件发送到手机。
3. 用随身复习器导入，完成训练。
4. 导出 StudyEvents JSON。
5. 回到桌面工作台导入；桌面重新评分和计算复习时间。

## 本地运行

```bash
python3 -m http.server 8788
```

然后用浏览器打开本目录对应地址。部署到 HTTPS 静态站点后可使用 PWA manifest / service worker。

## 数据边界

- 不连接桌面 SQLite。
- 不直接同步 `due_at`、streak 或 mastery。
- 只在本机浏览器保存当前 Pack 与尚未同步的 Attempt 事件；这意味着题目、答案和来源摘录也可能进入该站点的 localStorage，公用设备使用后应清理站点数据。
- 闪卡是自评证据；挖空离线只做临时字面核对，桌面导入时重新评分。
- 导入时会重新计算并核对 StudyPack 的 SHA-256 完整性；文件被误改或损坏会拒绝训练。
- 重复导出同一批 StudyEvents 不会造成重复学习记录；桌面按 event id 幂等处理。

## 当前限制

- v0.1 只支持 flashcard / cloze。
- StudyPack 是明文私有学习文件，不应直接公开分享商业教材片段。
- 真机 PWA 安装、Service Worker 和浏览器被杀后的恢复仍需要实机 Alpha。
