# M3A 功能原子运行时追溯

本表只记录 `law_full_recall_v1@0.1.0` 实际引用的 12 个功能原子。它不代表 259 个原子已经全部映射或实现。

| 原子 | 审计定义摘要 | 本切片落点 | 实现程度 |
|---|---|---|---|
| SEM-08 | 识别段落主要功能与核心句 | 核心设问以标题和来源前部主线做恢复检查 | 部分：启发式 |
| RET-02 | 从框架到要素、例外和细节的提取梯度 | 作答前五维检查顺序与修复动作 | 部分：训练提示 |
| LAW-14 | 拆解规则启动条件 | 规则模式句提取与来源覆盖 | 部分：文本启发式 |
| LAW-15 | 标注条件 AND/OR 关系 | 训练检查项明确要求关系恢复 | 仅训练约束，未结构化解析 |
| LAW-19 | 准确调用法条、概念、要件与结论 | 规则与要件维度、来源术语命中 | 部分：来源恢复 |
| STR-06 | 原则—例外模型 | 例外维度独立于一般规则 | 部分：模式词检测 |
| LAW-17 | 例外阻断 | 提取例外、限制和不适用条款 | 部分：文本启发式 |
| SEM-15 | 概念适用与排除边界 | 例外与边界训练项 | 仅来源内边界，不做外部比较 |
| LAW-16 | 规则触发后的法律效果 | 权利、义务、效力、责任和程序后果检查 | 部分：模式词检测 |
| QUA-03 | 术语与限定词准确性 | 来源术语命中率 | 部分：字符串启发式 |
| QUA-04 | 条件、结论、例外的一致性 | 规范连接词和结构检查项 | 初步，尚无逻辑冲突求解 |
| OUT-07 | 完整规则、论证、适用和结论展开 | 术语与规范表达维度 | 仅表达恢复，不生成高分标准答案 |

## 代码位置

- 原子声明与五维映射：`app/services/method_packs.py::_DIMENSIONS`
- 方法路由：`select_method_pack`
- 五维诊断：`evaluate_method_pack`
- 降级快照：`degraded_method_pack_snapshot`
- 会话冻结与持久化：`app/main.py::_method_pack_selection`、`start_session`、`submit_attempt`
- 用户界面：`app/static/app.js` 的方法包与诊断渲染逻辑
- 行为测试：`tests/test_method_packs.py`

## 未实现的能力

当前实现没有完成正式争点识别、法条效力核验、事实—要件映射、相邻制度推理、学说比较、评分点预测或高分答案生成。后续不能因为界面显示五个法学维度，就把启发式来源覆盖描述成专业法学评分。
