# v0.8.0 Portable Study 实现报告

日期：2026-08-08
状态：`EDITED + LOCALLY_VERIFIED`，无 Git 元数据。
Schema：4（未升级）。

## 本轮目标

用最小垂直切片证明：闪卡和挖空可以脱离桌面工作台完成训练，训练结果以事件形式安全回灌桌面，并由桌面 Runtime 重算正式进度。

## 已实现

- `StudyPack v0.1` 导出 API：`GET /api/study-pack/export`。
- `StudyEvents v0.1` 导入 API：`POST /api/study-events/import`。
- item version/hash 绑定。
- pack id/hash 身份校验；Portable Reviewer 在训练前也会重算 canonical SHA-256，拒绝被修改/损坏的 StudyPack。
- event id 幂等导入。
- `base_last_attempt_id` 因果基线与 `history_advanced` 冲突。
- 设备时间未来异常、事件早于 Pack 的冲突保护。
- 允许范围内的设备时钟轻微回拨会统一校正 Attempt 时间与 scheduler 基准，避免 due_at 时序脱节。
- imported attempt 使用 `snapshot_status=portable_v0`。
- flashcard 保持自评；cloze 在桌面重新执行正式 grade。
- ReviewState 只由桌面 scheduler 重算，不从移动端导入。
- 设置页增加 StudyPack 导出、StudyEvents 导入和冲突回执。
- 独立 `portable-reviewer/`：静态 HTML/CSS/JS/PWA shell，无桌面 API 依赖。
- 移动端未导出会话本地恢复逻辑。

## 关键架构证明

真实链路已跑通：

1. Uvicorn/FastAPI 生成真实卡片。
2. 真实 API 导出 StudyPack。
3. Chromium 独立加载 portable reviewer 与真实 StudyPack 文件。
4. Chromium 完成 flashcard + cloze。
5. Chromium 下载真实 StudyEvents 文件。
6. HTTP 客户端把该文件回灌真实 FastAPI。
7. FastAPI 导入 2 个事件并更新 SQLite ReviewState。

该测试不让 portable reviewer 调桌面 API，因此验证的是“文件协议解耦”，不是同一应用内的隐藏调用。

## 对抗项

已覆盖：

- 重复导入同一事件；
- 桌面在离线期间已经学习同一卡片；
- 卡片版本/hash 变化；
- 未知 pack；
- pack hash 不匹配；
- 设备时间明显未来；
- 事件明显早于 pack；
- cloze 移动端评分不作为权威，桌面重算。
- Portable Reviewer 对篡改 Pack 的浏览器级拒绝。
