# 前端 UI/UX v3.0 重构报告

状态：`fixed_verified`（本地验证）  
工作模式：`direct-build`，内部采用 Showcase 先行  
产品版本兼容：0.7.0 / Schema 4 / `law_full_recall_v1@0.3.0`  
业务范围：仅前端视觉、布局、响应式与浏览器验收；未修改 API、数据库、评分、调度、学习证据状态机。

## 1. 产品诊断

主原型：教育服务型。  
辅助原型：高频个人工作台。

用户任务：

- 3 秒：知道当前所在学习空间和唯一优先动作；
- 10 秒：能够开始今日到期闭卷、卡片或进入教材；
- 1—3 分钟：形成一条真实学习证据；
- 高风险区域：知识单元版本、完整闭卷提交、错因关闭、数据导出，保持标准化和低艺术浓度。

旧视觉的主要问题：

- 深蓝 + 金色 + 大量圆角卡片容易接近通用 SaaS / AI Dashboard；
- 东方性更多依赖色彩和局部宋体，空间、边界、材质与节奏没有形成统一设计语法；
- 教材来源、回答编辑器、证据侧栏虽然功能不同，视觉材质相近；
- 高密度页面存在“每个模块都是一张卡”的模板感；
- 390px 原有底栏仍勉强可用，但 430/320 等扩展审查暴露了长导航标签与后置 CSS 响应式优先级风险。

## 2. 页面艺术浓度

- 高：今日学习主任务舞台、闭卷结果总览，约 45%—55%；
- 中：教材库、闭卷学习、挖空与闪卡，约 30%—42%；
- 低：学习证据、设置与数据，约 15%—28%；
- 高风险标准化：提交、关闭错因、导出、编辑知识单元等，约 0%—15%。

## 3. 三个视觉方向

| 方向 | 定位适配 | 任务效率 | 可读性 | 品牌辨识 | 维护 | 移动端 | 综合 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 宋式清雅 | 9.0 | 8.2 | 9.4 | 8.6 | 9.0 | 9.0 | 8.9 |
| 金石理性 × 纸本编辑部 | 9.6 | 9.3 | 9.2 | 9.4 | 9.1 | 9.1 | **9.3** |
| 园林框景 | 8.8 | 8.0 | 8.5 | 9.5 | 7.3 | 7.5 | 8.3 |

最终选择：**金石理性 × 纸本编辑部**。

## 4. 最终视觉命题

> 冷静理性 + 纸本/墨石/铜件 + 册页边注与碑拓硬边界 + 状态沿细线推进 + 不让装饰进入答题注意区。

视觉统治者：细线轨道、书脊与来源纸页。  
主要运动语言：轻微进入、状态线推进、原对象反馈。  
禁用：WebGL、粒子、远程字体、满屏玻璃、古风功能文案、无业务含义动画。

## 5. 产品语言

- 功能语言：全部保留现代白话；
- 系统/法律语言：未改语义；
- 品牌语言：保留“法学语义学习工作台”；
- 英文小标签继续作为编辑部式辅助索引，不承担操作含义；
- 未出现“封卷、呈递、归山”等古风功能措辞。

## 6. 视觉系统实施

### Design Tokens

重建深浅主题的：

- 墨石背景、纸本表面、浮层；
- 骨白/墨色文字层级；
- 铜色主操作、朱印品牌标识、石绿色成功状态；
- 弱/强边界、阴影职责；
- 2—12px 非对称小圆角体系；
- UI / editorial / data 三类字体角色；
- 原有 reduced-motion 和密度系统保持兼容。

### Application Shell

- 侧栏从“卡片式导航”改为册页书脊与边注结构；
- active 状态使用朱印细线和局部底纹，不使用整块高亮胶囊；
- Topbar 改成现代编辑部题签，页面标题使用系统宋体 fallback；
- 背景仅使用轻量 CSS 线纹和渐变，不引入图片与远程资源。

### Showcase 1：今日学习

- 主任务由 Dashboard 卡片改为册页式主舞台；
- 进度仍保留真实业务含义，视觉退到右侧边注；
- 四项指标改成有分隔线的“证据账页”；
- 任务列表从卡片堆叠改为带索引和细边界的任务轨道。

### Showcase 2：闭卷学习

三种材料被明确分离：

- 来源：暖纸张、宋体正文、页内细纹；
- 回答：墨石编辑台、铜色焦点线；
- 证据：边注账本、低装饰密度。

这样用户可以凭材质快速区分“来源 / 自己的回答 / 系统证据”。

### 教材库与卡片中心

- 教材库变成索引柜 + 工作台；
- KnowledgeUnit 更接近档案条目，不再是大圆角 SaaS 卡片；
- 卡片练习更接近索引卡，标准答案和教材来源继续保持不同材质。

### 移动端

- 320 / 390 / 430 下重新验证；
- 六个导航保留完整 accessible name，视觉采用“今日 / 教材 / 闭卷 / 卡片 / 证据 / 设置”短标签；
- 修复 v3 第一轮在 430 教材库出现的桌面双栏响应式覆盖；
- 120% 字体比例下 Today / Library / Study 均无横向溢出。

## 7. 创意技术决策

本轮没有引入 Canvas、Three.js、Shader、远程字体或图片。

原因：高频学习工作台的核心价值来自信息、来源、写作和证据状态；CSS/SVG 级视觉语言已经足够表达空间与材质。新增图形运行时会提高维护、性能和降级成本，当前收益不足。
