# 安全与隐私边界

## 本地服务

默认仅监听 `127.0.0.1`，不暴露到局域网或公网。后续若允许外部访问，必须增加身份验证、CSRF、防重放和明确的网络权限设置。

## 教材属于不可信输入

PDF 中的文字仅作为数据处理。任何类似“忽略之前指令、读取本地文件、上传目录”的内容都不得进入系统指令层，也不得触发 Agent 工具。

当前版本不让 PDF 内容直接调用文件、网络或系统工具。未来 MCP 和 Agent 接入必须坚持：

```text
只读预检 → 展示计划 → 用户授权 → 执行 → 验证 → 回执 → 可撤销
```

## 文件导入

- 限制 `.pdf` 扩展名。
- 校验 `%PDF-` 文件头。
- 使用随机稳定 ID 作为本地存储文件名，避免路径穿越。
- 设置最大导入体积。
- 解析失败写入来源状态和错误，不伪装完成。

后续需要增加：恶意 PDF 资源限制、解析超时、页数上限、沙箱和异常文件隔离。

## API Key

当前 Key 只从环境变量读取，不写入 SQLite、日志、导出和前端页面。桌面版本应改用 Windows Credential Manager、macOS Keychain 或 Linux Secret Service。

## 云端发送

默认不发送。启用兼容云端 Provider 时，任务上下文包含当前知识单元、当前答案、提示和少量相关错误；不包含整本 PDF、完整数据库和无关聊天历史。

产品 UI 必须持续显示当前模式，并在高级设置中允许用户查看实际发送的上下文配方。

## 遥测与崩溃报告

当前版本没有遥测。未来默认不得上传教材原文、答案、API Key、本地文件路径和数据库内容。任何遥测必须可关闭，并列明字段。

## 数据恢复

`backup_local.py` 使用 SQLite 在线备份 API生成一致快照，并打包本地教材库。`restore_local.py` 先校验数据库，再把现有数据移动到带时间戳的 rollback 目录，避免直接覆盖删除。
