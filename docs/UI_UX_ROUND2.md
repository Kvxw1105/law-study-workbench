# v0.4.0 第二轮 UI / UX 深度重构

## 1. 状态与保护边界

当前状态：`LOCALLY_VERIFIED_REAL_USER_ACCEPTANCE_PENDING`

本轮只重构前端呈现、交互组织、响应式、可访问性和浏览器侧偏好。以下内容保持冻结：

- SQLite Schema 3 及既有数据语义；
- PDF 导入、知识单元、闭卷会话、卡片、评分、复测与导出 API；
- 闪卡服务端揭示约束、历史快照、证据权重和重启恢复；
- 本地优先、最小云端上下文和数据可导出的产品不变量。

## 2. 产品诊断

主原型：**教育服务型学习工具**。

辅助原型：**高密度个人工作台**。

用户进入后的时间目标：

- 3 秒内知道今天最该完成的学习任务；
- 10 秒内能够进入闭卷、到期卡片或教材知识单元；
- 1–3 分钟内产生一条真实学习证据，例如草稿、卡片评分或完整闭卷提交。

高频用户最怕的摩擦：

- 打开后仍要自己判断从哪里开始；
- 各页面只是卡片堆叠，缺少任务优先级；
- 来源、作答、证据权重和下一步散落在不同区域；
- 桌面和手机使用同一布局，导致信息拥挤；
- 弹窗依赖 `prompt()`，无法核对上下文和字段状态。

## 3. 视觉命题

> 冷静的法学档案室 + 哑光学习仪器 + 证据轨道；状态沿轨道推进，金色只标记来源、焦点和完成动作，装饰服从高频学习。

视觉统治者：**任务与证据轨道**。

主要材质：深色哑光工作台、暖色纸张来源面板、少量金属金强调。

禁止项：

- 满屏同尺寸玻璃卡片；
- 通用紫蓝渐变科技风；
- 无业务含义的粒子、图表和动效；
- 所有按钮同时高亮；
- 用大标题和留白掩盖缺少任务结构；
- 移动端整体缩小桌面布局。

## 4. 信息架构

### 今日学习

状态优先级固定为：

```text
未完成闭卷会话
→ 到期完整复测
→ 到期挖空与闪卡
→ 建议开始的新知识单元
→ 今日已清空 / 导入教材
```

页面只保留一个主行动，同时展示今日轨道、证据账本和后续任务队列。

### 本地教材库

分成两层：

```text
来源轨道：导入、选择、解析质量、页数、单元数
知识单元工作区：搜索、筛选、来源回指、卡片生成、完整闭卷
```

来源选择和知识单元操作不再混在同一张卡片内。

### 闭卷学习

采用三阶段状态：

```text
1. 闭卷提取
2. 来源对照
3. 修复复测
```

桌面布局：来源面板、回答编辑器、会话证据栏。

来源默认隐藏。使用一级提示或完整原文后，证据栏同步显示提示债务。编辑器显示字数、草稿状态、置信度和提交快捷键。

### 挖空与闪卡

分成三种视图：

```text
队列指挥台
→ 专注练习
→ 结果与下一次复测
```

卡片库支持搜索和类型/状态筛选。闪卡支持空格显示答案、数字 1–4 评分；挖空支持 Enter 提交。

### 学习者模型

页面只展示可追溯结果：掌握分布、置信度校准、反复错误、卡片提取与最近作答。不会用一段泛化人格总结覆盖原始证据。

## 5. 共享组件与状态

本轮建立并统一：

- Application Shell、Sidebar Pulse、Topbar Context、Mobile Dock；
- Primary / Secondary / Ghost / Danger Button；
- Status Pill、Evidence Badge、Task Lane、Source Rail；
- Workspace Panel、Source Paper、Result Hero、Review Ticket；
- Search Field、Filter Chip、Dialog Form、Toast；
- loading、empty、success、warning、error、disabled、focus-visible 和 destructive 状态。

动效只解释状态：页面进入、队列进度、来源展开、对话框打开和提示/结果变化。`prefers-reduced-motion` 与界面“减少动效”设置均可关闭非必要过渡。

## 6. 本地 UI 偏好

以下设置保存到浏览器本机存储：

```json
{
  "theme": "dark | light | system",
  "density": "comfortable | compact",
  "motion": "full | reduced",
  "fontScale": "90 | 100 | 110 | 120"
}
```

实际实现中的 `fontScale` 保存为百分比字符串，并在渲染时转换为 CSS 缩放系数。浏览器禁止本地存储时，当前会话仍会立即应用设置，只是不跨重启保存。

## 7. 响应式预算

- 1440px 左右：完整侧边栏、三列闭卷工作台和高密度任务队列。
- 1024–1240px：双列或单列重排，来源面板取消 sticky。
- 390–430px：隐藏桌面侧边栏，使用底部导航；主操作保持接近 44px；结果、来源和复测工单纵向排列。
- 矮窗口：允许正文安全滚动，固定层不得覆盖核心按钮。

所有浏览器验收页面执行 `scrollWidth <= clientWidth + 1` 检查。

## 8. 键盘与可访问性

- 页面具有“跳到主要内容”链接；
- 当前导航使用 `aria-current="page"`；
- 对话框使用原生 `<dialog>` 与可聚焦表单字段；
- `focus-visible` 具有清晰轮廓；
- 输入框和中文输入法组合期间不触发全局快捷键；
- 颜色之外还有文字、图标或位置表达状态；
- 移动端主按钮与导航接近或高于 44px 触控高度。
